# 🍱 FoodShare AI

An AI-powered surplus food donation system that helps reduce food waste by analyzing surplus food, determining donation priority, matching food with suitable recipients, and recommending donation actions.

## 🌍 Problem

Large amounts of edible surplus food are wasted every day while many people and community organizations need food.

FoodShare AI provides a simple technology-based solution to connect surplus food with suitable recipients.

## 💡 Solution

FoodShare AI uses multiple AI agents to process a food donation:

```text
User
  ↓
Food Details / Food Image
  ↓
Food Analysis Agent
  ↓
Priority Analysis
  ↓
Recipient Matching Agent
  ↓
Action Recommendation Agent
  ↓
Donation Record
  ↓
Dashboard
